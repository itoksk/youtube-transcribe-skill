# Claude Code: Practical Tips and Tricks — 概要のまとめ

> Source: https://www.youtube.com/watch?v=6eBSHbLKuN0
> Speaker: Boris（Anthropic Member of Technical Staff、Claude Code 作者）
> 文字起こし: `claude_code.en.md` / `claude_code.ja.md`

## 1行サマリ

Claude Code 作者の Boris が、Anthropic 社内で実践されている **段階的な使い始め方** と **チームに展開するためのコンテキスト設計** を、コードベース Q&A → コード編集 → 自社ツール統合 → CLAUDE.md 階層化 → SDK 活用、という順で解説した実践的トーク。

## 章立てサマリ

### 1. イントロ & Claude Code とは（00:00 - 02:53）

- Boris は Claude Code 作者。話は理論ではなく実践に振り切る方針
- Claude Code は **完全にエージェント的な** AI コーディングアシスタント。1行補完ではなく、機能・関数・ファイル単位、バグ全体を扱う
- 既存の IDE / ターミナル / ローカル / SSH / tmux 全部で動く。ワークフローを変える必要なし
- 自由度が高すぎて最初は迷うのが普通

### 2. 初期セットアップ（02:53 - 04:14）

- `/terminal-setup`（Shift+Enter で改行）
- `/theme`（ライト・ダーク・色覚多様性）
- `/install-github-app`（Issue/PR で `@mention Claude`）
- 許可ツールのカスタマイズで承認プロンプトを減らす
- macOS の Dictation を 2 回押しで使えば、プロンプトを音声入力できる

### 3. Tip 1: コードベース Q&A から始める（04:14 - 07:21）

- 新しいユーザーやチームへの導入は **必ず Q&A から**
- インデックスなし、アップロードなし、コードはローカル、生成モデルの訓練にも使われない
- 「このコードはどこで使われている？」「Git 履歴で引数の経緯を辿って」「今週何をリリースした？」など、Wiki やドキュメントで得るような深い回答が返る
- システムプロンプトに細かい指示を埋めているわけではない。**モデルが優秀** だから Git の使い方も自分で知っている
- Anthropic では技術オンボーディングが **2〜3週間 → 2〜3日** に短縮された

### 4. Tip 2: コード編集に進む（07:21 - 10:00）

- 渡している基本ツールは「ファイル編集 / Bash 実行 / ファイル検索」の3種類だけ
- 細かい手順を指示しなくても、Claude Code が自分で組み合わせる
- **大きな変更を頼む前に「ブレスト → 計画 → 承認 → コード」を頼むのが鉄則**
- 呪文: `ultrathink for this one, then commit, push, PR`（思考 → コミット → push → PR まで自走）

### 5. Tip 3: チームのツールを差し込む（10:00 - 11:02）

- bash ツール: 自社 CLI を Claude Code に教えて、`--help` で使い方を理解させる
- MCP ツール: 同じく教えれば使える
- よく使うものは `CLAUDE.md` に書いてセッションをまたいで覚えさせる
- 新しいコードベースで使い始めるとき、**チームが既に使っているツール一式を全部渡す** のが強力

### 6. ワークフローの型（11:02 - 12:14）

- 型1: 「探索 → 計画 → 確認 → コーディング」
- 型2: **フィードバックループによる反復改善**
  - ユニットテスト / Puppeteer スクショ / iOS シミュレータスクショなど、自分で結果を確認できる手段を渡すと、Claude が反復してほぼ完璧まで仕上げる

### 7. Tip 4: コンテキストを与える（CLAUDE.md と階層）（12:14 - 18:40）

- `CLAUDE.md` をプロジェクトルートに置けば毎セッション自動で読み込まれる
- ローカル `CLAUDE.md`（チェックインしない）／プロジェクト `CLAUDE.md`（チェックインしてチーム共有）／ネスト `CLAUDE.md`（その配下で作業時に自動ロード）／エンタープライズ `CLAUDE.md`（全社配布）
- 内容は「よく使う bash コマンド・MCP ツール・アーキ判断・重要ファイル」。**短く保つ**
