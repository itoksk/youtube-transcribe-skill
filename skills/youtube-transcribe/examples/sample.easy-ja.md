# Claude Code を使いこなすコツ — やさしい日本語での解説

> 元の動画: https://www.youtube.com/watch?v=6eBSHbLKuN0
> 詳しい文字起こし: `claude_code.en.md` / `claude_code.ja.md`
> 概要のまとめ: `claude_code.summary.md`

## この動画について

Anthropic 社のエンジニア Boris さんが、自分が作った **Claude Code**（クロード コード）という AI ツールの「上手な使い方のコツ」を話している動画です。
Claude Code は、プログラムを書く仕事を助けてくれる AI です。会社では、ほとんどのエンジニアが毎日使っているそうです。
この動画では、初めて使う人がつまずきにくい順番で、コツを 4 つに分けて教えてくれます。

---

## ポイントを順番に見ていきましょう

### 1. Claude Code ってどんな AI ？

ここで言いたいこと: Claude Code は「コードを丸ごとお願いできる AI」です。

これまでの AI は、コードを「1 行だけ」「数行だけ」予測してくれるものが多かったです。
Claude Code はそれよりもっと自分で考えて動きます。「機能を 1 つ作って」「このバグを直して」という大きな仕事をお願いできます。
こういうタイプの AI を **エージェント的な AI** と呼びます。「自分で道具を選んで、自分で進める AI」というイメージです。

特別な開発ソフト（IDE）を使わなくても動きます。ターミナルというシンプルな画面さえあれば動くので、好きな道具と組み合わせて使えます。

次の話: 「では、初めて開いたとき、何から始めれば良いでしょうか？」

---

### 2. 最初は「コードに質問する」ところから始めよう

ここで言いたいこと: いきなりコードを書かせず、**質問から始める** のが一番おすすめです。

Anthropic 社では、新しく入った人にもこのやり方を教えています。
入社初日に Claude Code を入れて、その日のうちに「このコードはどこで使われていますか？」と聞き始めるのです。

質問の例:

- 「この関数は、どこから呼び出されていますか？」
- 「Git の履歴を見て、なぜ引数がこんなに増えたのか教えてください」
- 「今週、私はどんな変更をリリースしましたか？」

Claude Code は、ただ言葉を検索するのではなく、コードを少し深く読んで、ちゃんとした答えを返します。
「Wiki に書いてあるくらい丁寧な答えが返ってくる」と考えてください。

このやり方をすると、新人の研修時間が **2〜3 週間から 2〜3 日** に短くなったそうです。

> 安心ポイント: あなたのコードは、どこかにアップロードされたり、AI の学習に使われたりしません。コードは自分のパソコンにそのまま残ります。

次の話: 「質問に慣れてきたら、いよいよコードを書かせてみましょう」

---

### 3. コードを書かせるときは「先に計画」を頼もう

ここで言いたいこと: いきなり大きな仕事を丸投げしない。**計画を先に立てさせる** のがコツです。

ありがちな失敗: 「3,000 行ある巨大な機能を作って」と一気に頼んでしまう → 出てきたものが思っていたものと全然違う、ということが起こります。
